# CV Versioning

This folder keeps one live CV and numbered snapshots.

- `Siqi_Guo_CV_2026_academia_main.tex` is always the latest editable version.
- `Siqi_Guo_CV_2026_academia_vN.tex` files are fixed snapshots copied from `main`.
- Before making a new substantial update, copy the current `main` to the next version number first.
- After the snapshot is created, make new edits only in `main`.
- PDFs should follow the same convention: `main.pdf` is latest, and `vN.pdf` is the compiled snapshot.

Current state:

- `v1` is the earlier 2026 academia snapshot.
- `v2` is the snapshot copied from the current `main` before the next round of edits.
- `main` remains the latest version and should receive the next updates.
